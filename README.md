# SkillSwap 技能互换平台

一个适合 GitHub Pages 部署的静态产品原型，用于展示「我能教的」和「我想学的」技能互换平台。

## 功能亮点

- 技能匹配广场：按技能关键词和分类筛选用户。
- 互换卡片：展示双方能教、想学、匹配分数、可约时间和试学入口。
- 发布流程：用户填写“我能教”和“我想学”，即时生成交换卡。
- 产品机制：包含时间银行、试学保护、技能证明和成长打卡。

## 部署方式

上传到 GitHub 仓库后，可直接用 GitHub Pages 部署：

1. 打开仓库 `Settings`。
2. 进入 `Pages`。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/root`。
5. 保存后等待 GitHub 生成公开链接。
