# SkillSwap 2.0

一个面向大学生和初入职场者的技能互换与长期共学平台原型。项目部署于 GitHub Pages，不依赖后端，面试官打开链接即可完整体验。

## 核心体验

- 技能广场：浏览技能卡、求学诉求和学习动态。
- 首登画像：多选“想学”和“能教”的技能，设置水平、空闲时间并上传能力证明。
- 配对雷达：按学习命中、双向互补、时间、水平、方式、证明和履约表现计算 100 分匹配。
- 交换旅程：管理申请、配对、排课、学习和复盘状态。
- 搭子信箱：发送消息、时间卡、作业卡和课堂邀请。
- 共学空间：调用浏览器摄像头、麦克风和屏幕共享，并记录课堂笔记。
- 同学圈与成长档案：沉淀作业、知识笔记和阶段成果。

体验数据保存在当前浏览器。结构化状态使用 `localStorage`，证明材料使用 IndexedDB。

## 本地运行

项目必须通过 HTTP 服务打开，不能直接双击 `index.html`。可使用任意静态文件服务器在仓库根目录启动预览。

## 测试

```bash
node --test tests/*.test.mjs
```

测试覆盖匹配权重、直接互换判定、时间重合、稳定排序、注册校验和交换状态流转。

## GitHub Pages 部署

仓库使用 `main` 分支根目录部署：

1. 打开仓库 `Settings → Pages`。
2. Source 选择 `Deploy from a branch`。
3. Branch 选择 `main`，目录选择 `/(root)`。
4. 保存并等待 Pages 更新。
